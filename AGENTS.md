# AGENTS.md — Binding Rules for All AI Agents

**Read this file, `STANDARDS.md`, and `GAUNTLET.md` before writing any code.**
Violating a numbered rule here is an automatic evaluator `blocker` gap.

1. **Stack.** React/TypeScript shell; **Three.js** for the 3D world
   (`src/modules/world3d`, since v2.0 — the Unity WebGL embed was retired);
   a Node WebSocket + SQLite server (`server/`) for realtime and persistence,
   Supabase Realtime kept as an alternate transport; realtime access hidden
   behind `src/modules/bridge/api.ts`. Do not introduce other frameworks.

2. **One public door per module.** Cross-folder imports go ONLY through the target
   folder's `api.ts` (TypeScript), `Api.cs` (Unity C#), or `api.py` (Python). The
   `arch:check` worker enforces this; internal files of another folder are invisible
   to you.

3. **Scope discipline.** Touch only the paths listed in your task's Scope section.
   If you must touch more, stop and return a gap instead of expanding scope.

4. **TDD, ordered commits.** First the failing test commit (`test(NNNN): red …`),
   then the implementation commit (`feat(NNNN): …`). No green-only submissions.

5. **No PII, ever.** Never request or store user names, emails, avatars, or LMS
   profile claims. Only opaque LTI `sub` keys. LTI scopes: `lineitem`, `result`,
   `membership` — nothing else (see STANDARDS §10).

6. **Localization.** Every user-facing string goes through the localization module
   dictionaries (en/es/pt). Run `pnpm i18n:check`; it must exit 0.

7. **module.yaml is mandatory.** Any new folder claims `name`, `description`,
   `version`, `api`, `depends_on`. Any capability change bumps that folder's
   version.

8. **Workers, not humans.** `SYSTEM.md` is regenerated by `pnpm system:update`;
   never hand-edit it. Register new public methods in your module's api file so the
   generator picks them up.

9. **NPC–player indistinguishability.** NPCs must use the same avatar generator and
   locomotion path as players. No visual flags, tags, or movement privileges that
   would leak "I'm an AI" (STANDARDS §5). Prospect/Hacker ambiguity is gameplay.

10. **Versioning.** Merging a task = bump `ROADMAP.md` version (vX.Y), squash-merge,
    delete the task branch. Milestone gates (M1–M4) are defined in ROADMAP.md.

11. **Performance floor.** In-browser world must hold ≥ 30 fps at 1280×720. Use the
    benchmark scene; avatar draw calls ≤ 4 each.

12. **Minigame authoring.** New game modes are single self-contained event files
    registered through the Minigames api (see `docs/DEVELOPMENT.md` §Event files).
    Never edit other modules to add a game.

13. **Supabase->Colyseus swapability.** Realtime code must reference only
    `bridge/api.ts` symbols (`joinWorld`, `leaveWorld`, `sendState`,
    `onState`, …). No Supabase client imports outside the bridge module.

14. **Evaluator rule builders must love.** The evaluator is independent by
    definition; a human harness may assign roles per round, never both to the same
    agent.

Humans: see `docs/DEVELOPMENT.md` for commands. Agents: keep prompts small; one
task, one component, one branch.
